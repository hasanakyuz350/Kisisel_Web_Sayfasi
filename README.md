🌐 Kişisel Web Sitesi

- **Bu proje, kişisel portföy ve blog niteliğinde hazırlanmış bir web sitesidir.
- **Ziyaretçiler projeleri inceleyebilir, yorum bırakabilir ve iletişim formu aracılığıyla e-posta gönderebilir.
- **Ayrıca siteye ait çevrimiçi demo bağlantısı üzerinden proje incelenebilir.

---

🚀 Özellikler

- **Kişisel tanıtım sayfası
- **Projeler sayfası: Proje detaylarını görüntüleme ve yorum yapabilme
- **Yorum sistemi: Ziyaretçiler projelere yorum bırakabilir
- **İletişim formu: Kullanıcıların doğrudan e-posta göndermesi
- **Demo bağlantısı: Projenin canlı sürümüne erişim imkânı

---

🛠 Kullanılan Teknolojiler

- **ASP.NET Core MVC (.NET 8.0)
- **Entity Framework Core
- **SQL Server
- **HTML5, CSS3, JavaScript
- **MailKit (E-posta gönderimi için)

📌 Notlar

- **Bu projeyi kullanmadan önce lütfen local ortamda gerekli veri tabanının kurulu olduğundan emin olun.
- **Yorumlar veritabanına kaydedilir ve proje sayfalarında görüntülenir.
- **İletişim formu üzerinden gönderilen mesajlar belirtilen e-posta adresine ulaşır.
- **Admin paneli, çoklu dil veya tema değişim özelliği bulunmamaktadır.
